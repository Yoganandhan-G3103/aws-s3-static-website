# AWS S3 Static Website Hosting

This project demonstrates how to host a static website using **Amazon S3** without managing a traditional web server.

The project focuses on secure and cost-effective website hosting by configuring an S3 bucket, IAM permissions, encryption, and static website hosting.

## AWS Services Used

* Amazon S3
* AWS IAM
* S3 Server-Side Encryption

## Key Implementations

* Created and configured an Amazon S3 bucket for website hosting.
* Uploaded HTML, CSS, and website files to the S3 bucket.
* Configured static website hosting.
* Implemented IAM permissions for controlled access to S3 resources.
* Enabled server-side encryption to protect stored objects.
* Tested the deployed website through the S3 website endpoint.

## Project Objective

To understand and implement **secure static website hosting on AWS S3** while gaining practical experience with **Amazon S3, IAM, permissions, encryption, and cloud-based website deployment**.
